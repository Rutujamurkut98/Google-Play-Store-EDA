# 📊 Google Play Store Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on the Google Play Store dataset to understand patterns, trends, and insights related to mobile applications. The analysis focuses on app categories, ratings, installs, and reviews using **Python**, **Pandas**, and **NumPy**.

The main objective of this project is to clean the dataset, perform structured analysis, and prepare the data for further analytics or machine learning tasks.


## 🛠️ Tools & Technologies Used

* Python
* Pandas
* NumPy
* Jupyter Notebook


## 📂 Dataset Description

The Google Play Store dataset contains information about various mobile applications available on the Play Store, including:

* App Name
* Category
* Rating
* Reviews
* Installs
* Type (Free/Paid)
* Price
* Content Rating


## 🔍 Steps Performed in EDA

1. Imported required Python libraries (Pandas & NumPy)
2. Loaded the Google Play Store dataset
3. Handled missing values
4. Removed duplicate records
5. Corrected data types for numerical analysis
6. Analyzed:

   * Unique app categories
   * App ratings distribution
   * Number of installs
   * Reviews count
7. Exported the cleaned and analyzed dataset to a CSV file


## 📈 Key Insights

* Identified the total number of unique app categories
* Understood the distribution of app ratings
* Analyzed install patterns across different categories
* Observed trends based on reviews and ratings


## 📤 Output

The final cleaned and analyzed dataset is exported as a CSV file for future analysis and use.
